🐝 Agent Hive

Self-hosted coding agent server. Send tasks, get a branch back. Every task runs in its own throwaway microVM.

Open App → GitHub

Features

🛡️

Every task in a microVM

Each prompt runs pi in a throwaway krun microVM with its own kernel. It sees a copy of the repo and one LLM key — never your SSH keys, gh login or server config.

🌿

Results on a new branch

The agent can't push. The server applies its commits to a clean clone as patches and pushes them to hive/<id>. Nothing lands on main without you.

🔍

Review cycles

Optional: a second agent (optionally a different model) reviews the diff, runs the tests, and fixes real problems before anything is pushed.

💬

Follow-ups

Send more messages to the same session: pi continues its conversation on the same working copy and the branch is updated.

🔌

MCP compatible

Use the REST API directly, the web UI, or any MCP client via hive-mcp.

🔀

Any provider

DeepSeek, Z.AI, OpenRouter, Anthropic or OpenAI — chosen per task. Only the selected provider's key enters the sandbox.

Quick Start

1. Get an API token

Generate a random token for authentication:

openssl rand -hex 32

2. Configure your MCP client

OpenClaw (openclaw.json):

{
  "mcp": {
    "servers": {
      "agent-hive": {
        "command": "npx",
        "args": ["github:stansz/hive-mcp"],
        "env": {
          "HIVE_URL": "https://hive.ogsapps.cc",
          "HIVE_TOKEN": "your-token-here"
        }
      }
    }
  }
}

3. Start coding

Use the tools from any connected client:

hive_prompt(prompt="Add rate limiting middleware", repo="owner/app", reviewCycles=1)
hive_status(sessionId="…")      # → resultBranch: "hive/1a2b3c4d"
hive_snippet(prompt="rename foo to bar", code="let foo = 1;")

How a task runs

POST /prompt {repo, prompt}
  host: git clone (deploy key) → origin/   — never mounted in a sandbox
  host: git clone --no-hardlinks → work/   — the sandbox's copy, no remote
  VM:   pi works in /work, commits
  VM:   review cycle(s), optional
  VM:   git format-patch → out/
  host: git am out/*.patch onto origin/, push → hive/<id>

The host never runs git inside the agent's copy, so hooks or config the agent writes there can't execute on the server.

Self-Host

Needs Linux, Node.js 20+, git and rootless podman. With /dev/kvm and krun, tasks run in microVMs; without, in rootless containers (see the README for what that means).

curl -sL https://raw.githubusercontent.com/stansz/agent-hive/main/install.sh | bash
cd ~/agent-hive && nano .env   # API_TOKEN + one provider key
node dist/index.js

See GitHub for systemd, Cloudflare Tunnel and deploy-key setup.
